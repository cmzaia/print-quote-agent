Print quote agent

GitHub

The LLM extracts the spec and asks questions; a deterministic cost engine does all the math. Describe a print job and get an itemized offset vs digital comparison with a recommendation.

Try an example

How it works

  1. Extract. The model pulls raw phrases out of your message.
  2. Normalize. Plain code maps them to a validated spec and decides what is missing.
  3. Price. The cost engine computes imposition, plates, clicks, finishing and rush in integer cents.
  4. Verify. A guardrail rejects any number the engine did not produce.

Demo runs with a rule-based stand-in for the model, no API key. Rates are fictional.
